# SynapSyS-MemorY

Motor de memoria independiente, local y modular para aplicaciones con IA.

Primera version: motor Python con SQLite/FTS5, adaptador MCP stdio opcional, aislamiento por espacios/proyectos y pruebas automatizadas.

La memoria se comparte solo entre conectores configurados expresamente con la misma base, espacio y proyecto. No almacenar secretos.

El codigo fuente, ejemplos y pruebas se incorporan en el siguiente commit.
